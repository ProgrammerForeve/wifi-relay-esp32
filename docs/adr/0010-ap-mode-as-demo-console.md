# ADR-0010: Captive-страница как демо-консоль, без токена в AP

## Статус
Принято. Дополняет ADR-0002 и ADR-0006.

## Контекст
Демонстрация перед аудиторией должна проходить без подключения к роутеру:
только телефон/ноутбук подключён к ESP32 напрямую. Captive-страница в AP-режиме
должна показывать диагностику и управлять реле.

ADR-0002 установил: управляющие эндпоинты защищены Bearer-токеном, потому что
без TLS канал открыт. ADR-0006 добавил на captive-страницу кнопку toggle,
требующую ручного ввода токена.

Но в AP-режиме клиент уже прошёл WPA2-аутентификацию на точке доступа — это и
есть защита канала. Требовать ещё и Bearer-токен поверх WPA2 в AP-режиме —
значит дублировать защиту и усложнять демонстрацию без выигрыша.

## Решение
Матрица доступа пересматривается:

| Эндпоинт              | STA            | AP            |
|-----------------------|----------------|---------------|
| GET  /api/status      | без токена     | без токена    |
| GET  /api/relay       | токен          | без токена    |
| PUT  /api/relay       | токен          | без токена    |
| POST /api/provision   | н/д            | без токена    |
| GET  /api/scan        | н/д            | без токена    |

Обоснование: в STA защита — Bearer-токен (сеть общая, WPA2 защищает только
радиоканал). В AP — WPA2-пароль точки, известный только тому, кто у точки.
Токен в AP-режиме не добавляет защиты, а мешает демо.

Captive-страница расширяется до «демо-консоли»:
- визуальная панель: индикатор состояния реле (крупно ON/OFF), режим Wi-Fi,
  IP, RSSI, uptime;
- кнопки «Обновить статус» и «Обновить состояние реле»;
- кнопка «ON / OFF» (toggle);
- форма provisioning SSID/пароль;
- CSS для читаемости при показе на проекторе.

## Альтернативы
- Оставить токен в AP (ADR-0002 без изменений): безопаснее на бумаге, но
  защита избыточна поверх WPA2, и демо требует ручного ввода токена.
- Токен только для PUT, статус без токена: непоследовательная матрица,
  которую трудно защищать.

## Последствия
+ Демо «из коробки»: подключился к ESP32 → открыл страницу → управляешь реле.
+ Меньше кода на странице (нет поля токена и JS для Authorization).
− В AP-режиме любой, кто знает WPA2-пароль, управляет реле. Пароль задаётся
  в Kconfig, известен ограниченному кругу; приемлемо.
− ADR-0002 остаётся в силе для STA; его матрица дополняется этим ADR,
  а не заменяется.
