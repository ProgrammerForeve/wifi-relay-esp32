# ADR-0008: Безопасное состояние — OFF, без персистентности

## Статус
Принято.

## Контекст
Реле управляет нагрузкой (в учебном стенде — светодиод/лампа, в реальности —
прибор). Поведение после подачи питания — вопрос безопасности, а не удобства.

## Решение
При старте реле всегда в состоянии OFF. Состояние не сохраняется в NVS и не
восстанавливается после перезагрузки. «Как было до выключения» не реализуется.

С учётом активного низкого уровня (ADR-0005) пин конфигурируется так, чтобы
до инициализации GPIO реле было обесточено, и только затем приводится
в состояние OFF программно.

## Альтернативы
- Восстановление последнего состояния из NVS: удобно для «умного дома»,
  но нагрузка может включиться сама после сбоя питания. Отвергнуто.

## Последствия
+ Предсказуемое и безопасное поведение при моргании света и перезагрузках.
+ NVS используется только для Wi-Fi-креденшелов — проще ментальная модель.
− Пользователь после перезагрузки видит выключенное реле и должен включить его
  заново. Для учебного стенда приемлемо; при необходимости — отдельный ADR.
