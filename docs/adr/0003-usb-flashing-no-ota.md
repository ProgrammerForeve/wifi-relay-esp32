# ADR-0003: Прошивка только по USB, OTA вне области работ

## Статус
Принято.

## Контекст
ESP-IDF поддерживает OTA (обновление по воздуху). OTA требует разметки разделов
ota_0/ota_1, проверки образа, обработки отката — заметный объём работы,
не связанный с основной задачей проекта (Wi-Fi-реле).

## Решение
Прошивка и мониторинг — только через USB: `idf.py flash monitor`.
OTA не реализуется. Таблица разделов остаётся стандартной.

## Альтернативы
- OTA: отлаживать по воздуху на ранних этапах рискованно; ценность для учебного
  проекта ниже стоимости.

## Последствия
+ Меньше кода и конфигурации.
+ Проще отладка: всегда есть последовательный порт.
− Обновление требует физического доступа к устройству. Для стенда приемлемо.
