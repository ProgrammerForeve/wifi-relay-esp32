# HTTP API: управление реле и диагностика

**Status:** ready-for-agent
**Blocked by:** 01, 02

## What to build

HTTP-сервер с управлением реле и диагностикой. Управление защищено
Bearer-токеном; диагностика — без токена. Мьютекс вокруг логического
состояния и GPIO по ADR-0007.

## Acceptance criteria

- [ ] `GET /api/relay` с токеном → `200` и `{"state":"on"|"off"}`;
      без токена или с неверным → `401`
- [ ] `PUT /api/relay` с телом `{"state":"on"|"off"}` и токеном → `200`,
      реле физически переключается; повторный `GET` подтверждает
- [ ] `PUT` с невалидным телом → `400` и `{"error":"..."}`
- [ ] `GET /api/status` **без токена** → `200`, JSON с режимом Wi-Fi, IP,
      RSSI, uptime, состоянием реле
- [ ] `/api/status` не содержит токен и Wi-Fi-пароль; SSID — только в AP-режиме
- [ ] Неизвестный путь → `404`, неверный метод → `405`
- [ ] Мьютекс вокруг «чтение — изменение — запись» GPIO
- [ ] Валидация тела выделена в чистую функцию (ADR-0009 — долг на будущее)
- [ ] Токен и Wi-Fi-пароль не появляются ни в одном ответе и ни в одном логе
