# Smoke-тест пройден и зафиксирован в отчёте

**Status:** ready-for-agent
**Blocked by:** 02, 03, 04, 05

## What to build

Полное прохождение чек-листа ADR-0009 на реальном железе с фиксацией
результатов в отчёте. Это верификационный срез, а не «написать документацию».

## Acceptance criteria

- [ ] Все 10 пунктов smoke-теста из ADR-0009 пройдены
- [ ] Для каждого пункта — результат (pass/fail) и, при необходимости, лог
      или скриншот
- [ ] Отчёт содержит раздел «Известные ограничения» со ссылками на ADR-0001…0009
- [ ] Схема подключения (LED, кнопка, реле, питание от блока) в отчёте
- [ ] API-контракт с примерами `curl` в отчёте
