# Wi-Fi: STA с сохранением креденшелов и fallback в AP

**Status:** ready-for-agent
**Blocked by:** 01

## What to build

Устройство подключается к сети по креденшелам из NVS; при их отсутствии или
неудаче через 30 с поднимает AP `ESP32-Relay-XXXX` с WPA2. При обрыве связи
в STA — backoff и переход в AP после ~5 минут. Captive portal пока нет:
креденшелы для проверки кладутся в NVS вручную (временный код удаляется при
приёмке).

## Acceptance criteria

- [ ] Креденшелы читаются из NVS при старте
- [ ] При успехе — STA, IP в логе с тегом `wifi_mgr`
- [ ] При отсутствии креденшелов или неудаче 30 с — AP, SSID
      `ESP32-Relay-XXXX` (последние байты MAC), WPA2, пароль из Kconfig
- [ ] При обрыве STA — backoff 1→2→4→8→…→60 с, каждая попытка — `WARN`
      с тегом `wifi_mgr`
- [ ] После ~5 мин непрерывных неудач — переход в AP
- [ ] Счётчик backoff сбрасывается при успешном подключении
- [ ] Токен и Wi-Fi-пароль не логируются ни на каком уровне
